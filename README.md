# RBC Command Scheduling System — public demo

Live demo of [Duty Belt](https://dutybelt.example)'s first product: planning and
compliance tracking for a California POST **Regular Basic Course (Standard
Format)** police academy.

### ▶ [Open the demo](https://arnold-enterprise.github.io/duty-belt-demo/)

**This is a demo build.** All instructor names are replaced with
`INSTRUCTOR A`–`G`. No real personnel appear anywhere in this repository.

### What it shows
- A full academy program — 906 scheduled blocks, sections A/B/C
- Live compliance against the POST regulatory floor (680 hrs: 606
  instructional across 43 active Learning Domains + 74 testing)
- Compliance computed **per section, worst section wins** — sections run
  parallel tracks of the same curriculum, so summing every block would
  triple-count
- PT tracker: 36 sessions + 3 WSTB + 3 fitness assessments inside 14 weeks
- Recruit roster with per-domain progress and deficiency tracking
- Calendar with federal-holiday closure detection and Excel export
- Import any academy's Master tab from `.xlsx`, in the browser

Single HTML file, zero dependencies.
